# The First Stone

An interactive cornerstone mystery from Escape Events, adapted from the HTML
previously embedded directly in Google Sites.

The standalone experience lives at [`public/first-stone.html`](public/first-stone.html).
The site root forwards visitors to that page, so the production root URL can be
used directly with Google Sites’ **Embed by URL** option.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Build the production version with:

```bash
npm run build
```
